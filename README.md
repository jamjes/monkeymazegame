# Baboom

Submission for the GDG Jam 4.0. An Arcade-Style co-op minigame about diffusing bombs before they explode.

## Description
Inspired by Jungle Run's Fort Maze, player's are spawned into a maze where they are tasked with locating the bomb and bomb kit. They must bring these components together to diffuse it before the level time runs out. Both monkey siblings aim to diffuse the most amount of bombs under the time limit by collecting whichever object they can reach to the quickest then meeting eachother to diffuse them.

## Getting Started

### Dependencies

* The project was created in Unreal Engine 5.4.4. To view the project files as intended, it is recommended to open the files in the same Unreal Engine version.
* This is a local co-op game, where player 1 is controlled by the keyboard and player 2 is controlled by a Unreal Engine supported controller. While the game is fully functional with 1 player, it is recommended and intended as a 2 player game.

### How to view the Unreal Engine Project

* Clone this repository to your system
* Open the project folder in Unreal Engine 5.4.4

### How to play this game

* Go to our [itch.io] page and click download, this should download the latest .zip file
* Exrtact the .zip file
* Open the executable
